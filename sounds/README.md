# Sounds

Put CC0 (public domain) clips here for themes that need real recordings, such as barks, meows, crackling fire and crowds. Keep them short (under 3 s, except alarms) and small: Opus/OGG or MP3, mono, under 100 KB.

A theme in `js/themes.js` refers to a clip like this:

```js
alarm: { clip: 'sounds/dog-bark.mp3', fallback: 'risingChime' }
```

If the clip is missing or can't play, the synth `fallback` plays instead.
